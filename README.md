# Track Recognizer

Android app: shows the genre of the song playing on your phone (SoundCloud, Spotify, YouTube
Music, …) in a notification, and in the app explains the style, the artist and similar artists.

**Download (always the newest version):**
https://github.com/PPADaniel/track-recognizer-app/releases/latest/download/TrackRecognizer.apk

1. Open the link on the phone and install the APK (allow your browser to install apps once).
2. Open Track Recognizer → **Allow access**. If Android calls it a restricted setting:
   App info → ⋮ → **Allow restricted settings**, then try again.
3. Play a song. Updates are offered inside the app.
